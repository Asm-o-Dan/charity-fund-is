## ⚡ ГЛАВНОЕ: Мобильность и работа «из коробки» (SQLite File DB)

База данных реализована в виде **локального файла `CharityFundDB.db`** (SQLite).  
**Никаких сторонних серверов СУБД, паролей и служб устанавливать не требуется!**  
Вы можете просто скопировать папку с проектом на флешку или передать преподавателю — приложение запускается сразу, без ошибок и всплывающих окон.

## 📌 Состав репозитория и материалы к защите

1. 💻 **`CharityFundApp/`** — исходный код работающего Windows Forms приложения на **C# 12 (.NET 8.0)**:

## 🚀 Быстрый запуск

### Запуск исполняемого файла
Дважды кликните на:  
`CharityFundApp\bin\Debug\net8.0-windows\CharityFundApp.exe`  
Приложение сразу откроется с готовыми данными.

### Запуск через Visual Studio 2022
1. Откройте `CharityFundApp.sln`.
2. Нажмите **F5** (Запуск).

### Запуск через консоль .NET CLI
```bash
dotnet run --project CharityFundApp\CharityFundApp.csproj
```

## 📊 5 аналитических запросов, реализованных в системе

1. **Сумма пожертвований:** общая сумма поступивших взносов, распределение по проектам, количество транзакций, даты первого и последнего взноса, фильтр по датам.
2. **Активные проекты:** программы со статусом «Активен», плановый бюджет, фактически собрано, процент выполнения цели и сумма к добору.
3. **Крупнейшие доноры:** рейтинг благотворителей (физ. и юр. лица) по совокупному объему внесенных средств с указанием количества платежей и даты последнего взноса.
4. **Расходы фонда:** баланс средств фонда (собрано, потрачено, свободный кассовый остаток) и журнал целевых списаний.
5. **Помощь по категориям:** распределение помощи по направлениям (детское здоровье, поддержка ветеранов, сироты, экология, малоимущие).
